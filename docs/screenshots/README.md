# Release screenshots

No screenshots are committed for `v0.1.0-rc.1`. This Linux preparation host has
no Android emulator/device and cannot run an iOS simulator, so creating imagery
here would not be evidence from a real runnable build.

When screenshots are produced:

1. Install the exact verified artifact on an emulator, simulator, or device.
2. Use invented names, items, notes, and photos only.
3. Capture the Exchanges, Record handoff, Exchange details, and Data and privacy
   screens at supported sizes; include large-text/accessibility variants.
4. Record artifact SHA-256, commit, platform/runtime, device profile, and capture
   command in the release evidence.
5. Label every simulator/emulator image as such; never imply physical-device or
   store-publication evidence.
6. Review images for notifications, paths, filenames, and other sensitive data
   before committing or publishing them.
